# Sitio público MaxPoint

Esta carpeta contiene la web institucional construida a partir de las guías maestras. Es independiente del sistema interno de gestión.

## Antes de publicar

1. Reemplazar las fotografías provisorias de `assets/images/` por material documental real, manteniendo los mismos nombres y proporciones.
2. Reemplazar las tres opiniones provisorias de `index.html` por reseñas reales y verificables.
3. Reemplazar los casos demostrativos de `casos-reales.html` y `caso.html` por trabajos reales documentados.
4. Confirmar dirección y teléfono: actualmente figuran `Av. 17 y 34, Mercedes` y `(2324) 522082`.
5. Incorporar horarios reales en `contacto.html` si se desea publicarlos. No se inventaron horarios.
6. Reemplazar el monograma textual `MP` por el logo definitivo si se entrega un archivo de marca optimizado para web.

## Publicación

Para usar esta web como sitio principal, subir el contenido completo de `sitio/` a la raíz del hosting público, conservando la estructura `assets/css`, `assets/js` y `assets/images`.

No publicar los PDF de guía ni este archivo si no se desea exponer documentación interna.
